# CS-309 Assignments

This repository contains my assignments for the CS-309 course.

## Assignment 1

Assignment 1 is a simple multi-page website created using HTML and CSS.

### Pages

- **Home** (`index.html`)  
  The main page of the website.

- **About** (`about.html`)  
  Contains information about the website.

- **Contact** (`contact.html`)  
  Contains a contact form with different HTML form elements.

### Contact Form

The contact page includes:

- Text input
- Email input
- Number input
- Date input
- Radio buttons
- Checkboxes
- Dropdown menu
- Textarea
- Submit button

### Technologies Used

- HTML5
- CSS3
